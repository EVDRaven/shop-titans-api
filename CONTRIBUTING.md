# Contributing — Shop Titans API

## Participantes
- Usuario: prioridades y decisión final.
- ChatGPT: arquitectura, análisis y revisión.
- Editor IA: implementación, pruebas y documentación.

## Flujo
`Usuario → ChatGPT → Editor IA → Reporte → AI_WORK_LOG → Revisión → Aprobación → Contexto/ADR/Changelog`

## Reglas
- Verificar hipótesis contra datos reales.
- Reportar discrepancias.
- No convertir propuestas en decisiones automáticamente.
- No confundir aprobación de implementación con autorización de ejecución.
- Documentar cada tarea técnica significativa.
- No adelantar módulos fuera del alcance.
- Revisar Git antes de tareas importantes.
